Digital Clock

Overview
    This project is a simple digital clock built using HTML, CSS, and JavaScript. 
    It dynamically updates the time every second and displays it in a clean, styled format.

Features
  Real-time clock that updates every second.
  Minimalist styling using CSS.

JavaScript-powered functionality for dynamic time updates.

Technologies Used
  HTML: Structure of the clock.
  CSS: Styling for a visually appealing design.
  JavaScript: Logic to fetch and update the current time.

Installation & Usage
  Clone or download the project files.
  Open index.html in a browser.
  The clock will automatically display the current time.

Code Structure
    index.html → Contains the clock structure.
    style.css → Defines the visual styling.
    script.js → Handles time updates.
